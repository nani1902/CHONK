# Session record template

Copy to `docs/discovery/sessions/P<n>.md` after each session. Every value is content-free: no document contents, file names, client or employer names, portal names that identify the participant, or contact details. Mark each value **O** (observed), **D** (described specific instance), or **E** (estimate). Leave `unknown` rather than guessing.
