# Decision records

Status legend:

- **Proposed** — written and argued, awaiting the repository owner's acceptance. Proposed records do not authorize anything.
- **Accepted** — the owner has signed off in the record's *Sign-off* section (name/handle, date, commit or PR). Only accepted records count toward the M0 exit gate in [TASKS.md](../product/TASKS.md).
- **Superseded** — replaced by a later record, which must link back.

Records must be content-free: no customer document contents, file names, client names, or identifying participant details. Discovery evidence lives in [`docs/discovery/`](../discovery/README.md) in the same content-free form.
